# Titanic Survival Analysis Dashboard

## Project Overview
An interactive Power BI dashboard analyzing Titanic passenger data.

## Tools Used
- Power BI Desktop
- DAX
- Data Visualization

## Dataset
Titanic Cleaned Dataset (891 records)

## Dashboard Features
- Total Passengers
- Overall Survival Rate
- Average Age
- Average Fare
- Gender-wise Survival Analysis
- Class-wise Survival Analysis
- Age Group Analysis
- Passenger Fare Distribution
- Interactive Slicers
- Passenger Survival Distribution
- Passengers by Embarkation Port

## Key Insights
- Overall survival rate was 38.38%.
- Female survival rate was 74.20%.
- Male survival rate was 18.89%.
- First-class survival rate was 62.96%.
- Children had the highest survival rate among age groups (57.97%).
